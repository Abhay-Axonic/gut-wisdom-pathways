# Project rules

- All brand, contact, location, fee, booking and analytics values live in `src/config/site.ts`; clinician facts in `src/config/clinicians.ts`. Unconfirmed values are `null` and must be hidden from public pages, never shown as placeholders — keeps the public site truthful.
- Owner-facing gaps go in `OWNER_CHECKLIST.md`, never in public copy.
- Consultation requests go through the `consultation-request` edge function into `consultation_requests` (service role only, RLS with no public policies); the UI shows success only on the function's `ok: true` — enquiries are private patient data.
- Every page renders `<Seo>` with a self-referencing canonical built from `productionUrl`; non-production hosts get noindex — avoids preview URLs competing with production.
- `public/sitemap.xml` and `robots.txt` are generated by `scripts/generate-sitemap.mjs` at build; add new routes there.
- Analytics events never include personal data and only fire after consent when a provider is configured.
- Section reveals run via `useSectionReveal` in Layout: content is visible by default and only hidden after JS adds `js-reveal`, with a timeout safety net and reduced-motion opt-out — text must never be stuck invisible.
- Heading sizes come from the global type scale in `src/index.css`; don't add text-size utilities to h1–h3.
